# rare Input: "free" concept site

A separate Next.js 16 site on an orphan branch (no shared history with `main`).
Conversion-led concept: free store check as the main offer, prices shown up front,
animated search-ranking hero.

Run: `npm install && npm run dev`. Contact form needs `RESEND_API_KEY` and
`CONTACT_FROM_EMAIL` (optional `CONTACT_TO_EMAIL`, `NEXT_PUBLIC_SITE_URL`).
