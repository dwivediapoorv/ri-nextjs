# Reference: UI block libraries

Shadcn-based libraries with ready-made marketing sections (heroes, pricing, FAQ, CTA, team, footers). Found 27 Nov 2026. Check each library's licence before using it in client work.

## Closest to Tailark (marketing sections)

- **Tailark** - 200 to 300+ marketing blocks, freemium (free blocks are MIT, Tailark Pro is paid). https://tailark.com · https://github.com/tailark/blocks
- **Shadcnblocks** - largest catalog (1,350+ blocks) plus multi-page templates; 55 free marketing blocks. https://www.shadcnblocks.com/blocks/marketing · free set: https://shadcnblocks.com/blocks/free
- **Shadcn Studio** - 750+ blocks, good Base UI support.
- **UI-Layouts** - 75+ free blocks (hero, pricing, testimonial, FAQ).
- **Creative Tim** - 123+ marketing blocks (heroes, testimonials, navbars, footers, contact forms, team). https://www.creative-tim.com/ui/blocks/marketing-presentation
- **shadcn.io** - very large directory of blocks and templates, including a listing for Tailark Blocks. https://www.shadcn.io/template/tailark-blocks
- **21st.dev** - community marketing blocks, first block of each category free. https://21st.dev/community/shadcn-directory/marketing

## If you want animation

- **Aceternity UI** - 200+ motion-rich blocks (paid).
- **Magic UI** - 150+ animated components, free (MIT).

## Whole-site starting points

- **Velora UI** - 32 animated blocks plus a finished multi-page template, free (MIT).

## Notes

- Names without links were not verified against their own sites; search for the official URL before relying on them.
- Our `free` branch is hand-built (no shadcn). Using these blocks would give faster pages but a more generic look unless restyled.
